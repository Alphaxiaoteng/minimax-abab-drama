# 提交材料大纲（PPT / 方案文档）

> 用途：官方提审的方案文档与 10 分钟路演 PPT 骨架。每页给出「标题 + 结论句 + 支撑证据」，照抄即可成稿。

---

## P1 封面
**沉浸式互动推理剧 Agent** —— 一个多重人格、情绪化声线、断网也能演的 AI 伴侣
副标：MiniMax abab 7 + T2A v2 · 含离线确定性降级与量化评测系统

## P2 痛点（三个通病）
1. **人格飘移**：第 3 轮就不像同一个人。
2. **声音与情绪脱钩**：角色在暴怒，声线依旧平静。
3. **演示不可靠**：依赖网络与密钥，评审现场断网即翻车。

> 支撑证据：本工程 `npm test` 全绿，其中含 33 条人格约束用例与端到端音频锚定用例。

## P3 解法（一句话）
把「人格 / 情绪 / 语音 / 剧情状态」做成**同一台状态机的四个投影**，并配一套**离线确定性的评测系统**。

## P4 产品形态
移动端优先的 H5 沉浸剧场：选人物 → 情绪化开场语 → 多轮审讯式对话 → 线索面板与亲密度/紧张度可视化 → 情绪驱动的氛围色过渡。

> 证据：`npm run serve` → `http://127.0.0.1:8787`，纯原生零构建，可直接部署为在线体验链接。

## P5 技术架构（一页图）
单向依赖链：`core 契约 → personas 人格库 → minimax 外呼层（唯一降级决策点）→ engine 导演状态机 → eval 评测 → server/ui/cli`
> 引用 `docs/ARCHITECTURE.md` 的流程图。

## P6 三个原创人格（差异化壁垒）
| 人物 | 定位 | 声线 (T2A voiceId) | 情绪范围 | 语言指纹 |
|---|---|---|---|---|
| 沈砚 | 冷面法医顾问 | `male-qn-jingying` | 6 类 | 短句、只谈证据 |
| 林小满 | 自媒体调查记者 | `female-shaonv` | 6 类 | 长句、爱插科打诨 |
| 何静澜 | 阴郁画廊主理人（**本案真凶**） | `female-yujie` | 6 类 | 隐喻修辞、情绪落差极大 |

> 证据：三人 `catchphrases` 交集为空（自动化断言），保证语言指纹可区分；`voiceId` 互异，保证听感可区分。

## P7 情绪闭环：标签 → 声学参数
模型在回复末尾产出 `（语气：X）`；`resolveVoiceSettings(base ⊗ emotionOverride)` 映射为 T2A v2 的 `speed/vol/pitch/emotion`，并夹紧到官方合法区间。
> 关键论点：**不是换标签，是换波形**。评测用「同文本 8 种情绪的音频首 200 字节互异」锚定。

## P8 剧情不变量由状态机保证，不交给 LLM
`phase` 只进不退；线索信任闸值严格递增（0→30→55→70→85→95）；`culpritId` 全局唯一；终局后拒绝继续输入（抛 `ValidationError`）。
> 理由：LLM 无法保证不变量；确定性状态机才能在演示中稳定复现。

## P9 降级层：异常永不逃逸
`TransportError` 触发重试 → 仍失败则**永久**切 `mock`，后续不再触网；降级原因归五类并写入报告。
> 证据：注入 `chatFailures: 3` 的伪传输层测试断言「无异常逃逸 + 降级后 transport 调用次数停止增长」。

## P10 评测验证系统（可量化壁垒）
6 维加权评分：人格一致性 0.22 / 情绪准确率 0.20 / 语音表现力 0.18 / 降级健壮性 0.15 / 延迟达标率 0.13 / 剧本完整性 0.12。
通过条件：`overall ≥ 0.75` **且**每维各自达标（防止高权重维度掩盖短板）。
> 证据：`npm run eval` → `artifacts/eval-report.md`。

## P11 演示视频锚点
见 `docs/DEMO_SCRIPT.md`：离线跑通 → H5 真实体验 → 无效密钥演示降级 → 评测报告数字。

## P12 商业化路径
- **B 端**：沉浸式剧本杀门店 / 文旅实景剧本 / 品牌拟人化客服。
- **C 端**：订阅制「多重人格伴侣」，按人物声线包售卖。
- **平台侧**：MiniMax 的 T2A 情绪化能力是转化关键，本工程可直接作为官方能力样板间。
