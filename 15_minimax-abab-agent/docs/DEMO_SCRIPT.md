**镜头**：终端 6 轮对话 + 末尾状态汇总表（阶段 / 亲密度 / 紧张度 / 已获线索 / 降级次数）。

## 00:55–02:00 ｜ H5 沉浸式体验（主镜头）

```bash
npm run serve     # → http://127.0.0.1:8787
```

手机宽度的浏览器窗口，按序演示：

1. **选人物**：三个人物卡片（沈砚 / 林小满 / 何静澜），标注各自声线与情绪范围。
2. **开场**：何静澜的地道白，点播放键 → 听到阴郁女声；屏幕顶部显示 `（语气：悲恸）` 与对应情绪色氛围。
3. **第 1 轮**：输入「你手上那幅画是谁的」→ 观察打字机输出、情绪标签刷新、氛围色过渡、亲密度/紧张度条增长。
4. **第 2 轮**：输入「你在撒谎，这和你之前说的对不上」→ 紧张度跳升、情绪切到 `tense`、**语音变调明显可听**。
5. **第 3 轮**：输入「我信任你，把你知道的都告诉我」→ 亲密度上升 → **线索面板新增一条线索**、阶段标记推进。

> 口播重点："注意这里——**不是换了标签，是换了波形**。"（停顿，让观众听到音色/语速差异）

## 02:00–03:00 ｜ 降级路径现场演示（技术亮点）

> 这是现场演示敢用的前提。"

**镜头**：终端出现降级提示条，但对话继续完整跑完 6 轮。

## 03:00–03:40 ｜ 评测系统（差异化壁垒）

```bash
npm run eval
```

**镜头**：`artifacts/eval-report.md` 的中文表格——6 个维度、权重、得分、阈值、结论。

> "我们把『感觉不错』变成了数字：人格一致性、情绪标注准确率、语音表现力、
> 降级健壮性、延迟达标率、剧本推进完整性。
> 语音表现力这一维，是用『同一句话在 8 种情绪下的波形首部必须互异』来锚定的——
> 也就是说，**情绪真的改变了声学特征，而不只是打了一个标签**。"

**镜头**：终端 `npm run eval` 的维度表，逐行高亮。
