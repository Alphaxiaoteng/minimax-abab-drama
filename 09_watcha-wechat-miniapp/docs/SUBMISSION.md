# 微信小程序应用开发大赛 · 参赛项目提交案 (Submission Dossier)

## 1. 项目定位与一句话价值 (Executive Summary)
- **项目名称**：Watcha MiniApp（观猹 · AI 一页纸快读 + 日程断舍离）
- **参赛赛道**：微信小程序应用开发大赛 · 创新企业与高校智能赛道（总奖金池 49万 元）
- **一句话价值**：基于原生小程序 + 微信云开发 AI 的双场景“秒开型”提效工具，兼备确定性离线内核，实现长文 0 秒开首帧与日程智能减负。

---

## 2. 核心痛点与技术突破 (Pain Points & Innovations)
1. **痛点一：传统 AI 小程序加载慢、冷启动白屏久**
   - *突破*：主包极致压缩至 89.7 KB（仅占微信 2MB 硬上限的 4.38%），采用首屏同步读本地状态、骨架屏按需加载与分包机制，实现首屏 t0 < 1ms。
2. **痛点二：网络抖动或大模型限流时服务假死**
   - *突破*：设计“双轨驱动与离线确定性兜底”。正常情况下通过云开发 AI 流式 SSE 输出；一旦断网或接口异常，立即无缝降级到本地离线规则与正则提取内核，确保 100% 产出有效卡片。
3. **痛点三：日程管理软件只做加法不做减法**
   - *突破*：首创“日程断舍离”算法，利用优先级权重、模糊时间消歧、相似度去重（≥80% 判定为冗余）主动帮助用户删除低价值事项。

## 3. 系统架构 (System Architecture)

```mermaid
flowchart TD
    User([微信用户]) --> MiniApp[微信原生小程序客户端]

        FallBackKernel[本地确定性规则引擎 (离线保活)]
    end
    
    subgraph CloudBase [微信云开发 AI]

        AIModels[DeepSeek / 混元 / 云开发 AI 模型矩阵]
    end
    
    MiniApp --> SyncCache
    SyncCache --> Skeleton
    Skeleton -->|在线请求| CloudFunc
    CloudFunc --> SSE --> MiniApp
    CloudFunc -.->|超时/断网熔断| FallBackKernel
    FallBackKernel -->|结构化卡片渲染| MiniApp
```
