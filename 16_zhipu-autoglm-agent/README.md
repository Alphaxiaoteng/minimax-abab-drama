## 一句话定位

基于 AutoGLM 决策闭环思想，构建「**多通道容错定位 + 屏幕健康自愈 + 可续跑业务流引擎**」的端侧 GUI 自动化框架，交付三条真实高频痛点闭环。

## 三条业务闭环

| 闭环 | 场景 | 交付结果 |
|---|---|---|
| 手机端跨平台比价领券 | 聚海严选 / 淘享岛 / 比邻红包三 App 比价、处理开屏广告与剪贴板权限弹窗、折叠区滚动采集、领券 | 最低到手价建议（示例：¥179） |
| 桌面端发票归集报销 | 企业邮箱 OCR 抓取发票金额并与「合计」行对账、财务系统填单、传附件、提交后回读单号 | 报销单号 + 发票合计（示例：BX-2026-1001 / ¥1250） |
| 手机端政务 App 会话重登与取证 | 开屏广告 → 权限弹窗 → 会话过期重登 → 短信验证码 OTP → 登录态分流 → 公积金余额查询 | 余额 + 可审计证据帧（示例：¥12345.67） |

## 技术选型理由

| 选型 | 理由 |
|---|---|
| **Python 标准库为核** | 评审/CI 环境零依赖即可跑通完整演示；`rapidocr` / `pyautogui` 等可选栈延迟导入并自动降级 |
| **UI 树优先于视觉** | `uiautomator dump` 便宜、稳定、无模型成本；OCR 与模板通道仅在无 UI 树场景启用 |
| **多通道融合定位** | 单一 `text` 选择器在真实 App 上极脆弱（文案 A/B、分辨率适配、OCR 误识）；四通道按成本递增 + 置信度融合，并做歧义二次确认 |
| **低置信兜底严格门控** | 模板/先验通道候选默认不被采信，仅在定位超时后放行，杜绝「静默误点」 |
| **健康自愈看门狗** | 真正的杀手是静默坏帧（黑屏/冻屏/弹窗遮蔽）；把「这一帧能不能信」变成可度量、可处置、可断言的信号 |
| **状态机虚拟设备** | 把 UI 漂移、弹窗、OCR 噪声、输入被清空变成可编程注入的测试变量，容错能力可被单测证明而非口述 |
| **检查点 + 每步校验** | 端侧自动化最大成本是「跑到 80% 挂了重头再来」；断点续跑 + `verify` 业务校验直接决定实测成功率 |

## 验收与复现命令

```bash
cd src
python3 run_demo.py                                  # 三条闭环离线演示（推荐评审路径，零依赖）
python3 -m pytest tests -q                            # 30 个用例全绿
python3 run_demo.py --chaos --trace trace.md         # 故障注入 + 导出执行轨迹（稳定性证据）
DEVICE=adb python3 run_demo.py                        # 安卓真机（缺设备自动回落虚拟，不中断演示）
DEVICE=desktop python3 run_demo.py                    # 桌面端（缺 pyautogui 自动降级并明确提示）
ZHIPU_API_KEY=sk-xxx python3 run_demo.py --agent "帮我比价买最便宜的蓝牙耳机"
```

> 真机路径（`DEVICE=adb` / `DEVICE=desktop`）在本机未验证：当前环境无 Android 设备、无 `pyautogui`。
> 已验证的是无设备时的降级路径（明确提示 + 回落虚拟设备，控制流不假成功）。

## 异常自愈能力矩阵

| 故障类型 | 检测手段 | 处置动作 |
|---|---|---|
| 开屏广告 / 升级弹窗 | 弹窗特征词 + 关闭词表 | 点关闭/跳过，循环至干净 |
| 权限弹窗 | 仅当页面含权限特征词时消费 | 点「允许」并记录事件 |
| 步骤执行后才弹窗 | 下一步动作前体检 | 发现 pending 弹窗即消化 |
| UI 元素漂移 | 多通道定位 + 歧义二次确认 + 点击前重校验 | 重新采样确认中心稳定后点击 |
| OCR 噪声/错字 | 文本归一化 + 编辑距离 + 多后端共识 | 单通道降权，交由 UI 树通道裁决 |
| 输入被清空/未写入 | `type_text` 回读校验（世界状态/元素 key/屏幕文本三层） | 重新定位 + 重键入，全失败则显式报错 |
| 黑白屏（未渲染） | 元素与文本双空 | 等 0.4s → `back` → 重启前台应用 |
| 冻结/卡死（ANR、点击被吃掉） | 动作**前后**签名完全一致 | `back` 打破僵局 → 累计 2 次重启应用 |
| 静止的正常页面 | 不得误判为冻结 | —（不处置，避免误伤正常页面） |
| 目标不在首屏 | 滚动探测（签名去重防死循环） | 自动翻页 + 失败回滚到顶 |
| 关键步骤持续失败 | 每步 `verify` 业务校验 | 退避重试 → `recover_back` → `fallback` → 落检查点中止 |
| 进程崩溃/设备掉线 | 检查点原子落盘 | `resume=True` 从断点续跑，上下文一并恢复 |
| 无 adb / 无图形后端 | 设备层异常归一为 `DeviceError` | 回落虚拟设备 / `NullDesktopBackend`，控制流照跑 |
